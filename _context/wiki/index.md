## Quick Facts

- **Language**: Python 3
- **Package manager**: `pip` / `pyproject.toml` + `setup.py`
- **Build**: `make install build`
- **Test**: `make unit-test` or `pytest test/src/mock`
- **Lint**: `make lint` (flake8) + pre-commit hooks (autopep8, flake8, detect-secrets)
- **Repo**: Open source, ~20–30 contributors
